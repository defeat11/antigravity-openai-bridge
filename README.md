# antigravity-openai-bridge

[English](README.en.md)

**يستقبل طلبات أي عميل OpenAI عادي، ويرجّع ردود Gemini من Antigravity ACP CLI ببث SSE حقيقي.**

خادم Node واحد، ما فيه ولا dependency خارجية: **1,711 سطر جافاسكربت**
(قياس: `wc -l server.js backends/*.js`) و`"dependencies": {}` في package.json.
يفتح 9 مسارات HTTP، أهمها `/v1/chat/completions` — يشتغل مع أي OpenAI SDK.

> ملاحظة مهمة: الجسر ما يشتغل لحاله. يحتاج
> [antigravity-acp](https://github.com/defeat11/antigravity-acp) المنشور على نفس الحساب،
> وملف `gemini-acp.js` اللي يصدّر `GeminiAcpClient`، وأداة `agy` مثبتة على جهازك.

## المشكلة

Antigravity CLI أداة برمجة تفاعلية. تقرأ نص وتكتب نص عبر stdio، وبس.

ما فيها HTTP، ولا توافق مع OpenAI، ولا نداء أدوات (tool calling).
وذاكرة الجلسة تروح لما تُقفل العملية.

بالمقابل، كل العملاء الجاهزين يتكلمون OpenAI: أي OpenAI SDK،
وواجهات مثل Open WebUI، وأطر الـ agents اللي ترسل `tools[]` وتنتظر `tool_calls`.

## كيف يشتغل

```
عميل OpenAI (SDK / واجهة ويب / إطار وكلاء)
  └─ server.js                    9 مسارات، بث SSE، أرشفة المحادثات
      └─ backends/acp.js          يبني الـ prompt ويدير الجلسة والحدود
          ├─ backends/toolbridge.js   بروتوكول نداء الأدوات النصي
          └─ gemini-acp.js (خارجي)    عميل ACP عبر stdio
              └─ antigravity-acp      المحوّل
                  └─ agy              النموذج نفسه
```

| الملف | الأسطر | الدور |
|-------|--------|-------|
| server.js | 881 | المسارات، وبث SSE بنبضة كل 15 ثانية، وصندوق أسود يسجّل الانهيارات |
| backends/acp.js | 469 | يبني الـ prompt، ويمسك آخر 20 دور بس، ويمنع تكرار نداء نفس الأداة |
| backends/session-anchor.js | 201 | يثبّت محادثة agy واحدة تكمل حتى لو رجّعت الخادم |
| backends/toolbridge.js | 160 | يحوّل مخططات الأدوات إلى بروتوكول نصي، ويقرأ النداء الراجع |

مع المشروع ملفا اختبار يشغّلون OpenAI SDK الحقيقي على الخادم:
23 فحص بالمجموع (قياس: `grep -c "check(" *.mjs` يعطي 14 + 9).

## أهم قرار في التصميم

**المشكلة:** أطر الـ agents ترسل `tools[]` وتنتظر `tool_calls`،
والنموذج خلف ACP ما يرجّع إلا نص عادي.

**القرار:** جسر أدوات نصي. أحط مخططات الأدوات جوّه الـ prompt على شكل بروتوكول صارم،
والنموذج يرد بسطر JSON واحد لما يحتاج أداة، بعدها `parseToolCall` يفكّه
ويطلّعه ردّ `tool_calls` عادي. التنفيذ يبقى عند العميل، مو عند الجسر.

**التكلفة/العائد:** في وضع الأدوات أجمع الرد كامل قبل ما أرسله،
فيروح البث حرف بحرف — عشان ما يطلع JSON البروتوكول للمستخدم.
والمكسب: أي إطار agents يتكلم OpenAI يشتغل فوق CLI ما يعرف نداء الأدوات أصلاً.

### قرار عكسناه بعد القياس

بنينا «مرساة جلسة» تثبّت محادثة agy واحدة عبر `ACP_AGY_EXTRA_ARGS`، عشان الذاكرة
تكمل بعد إعادة التشغيل. بعدين صار اللي غيّر رأينا، وفيه تعليق في `server.js` يوثّقه:
إعادة بث المحادثة المثبّتة وقت الإقلاع طلّعت رد واحد طوله **280,901 حرف**
علّق الجلسة. لكن العميل يرسل التاريخ كامل في كل طلب على أي حال،
فخلّينا المرساة مطفية افتراضياً، وتنشغّل بـ `GEMINI_SESSION_ANCHOR=on` لو احتجتها.

## التشغيل

```powershell
Copy-Item .env.example .env
node --env-file=.env server.js
curl http://127.0.0.1:3010/api/health
```

عشان يظل شغال على طول في ويندوز:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File keepalive-gemini3010.ps1
```

| المسار | الطريقة | الوظيفة |
|--------|---------|---------|
| /v1/models | GET | قائمة نماذج بصيغة OpenAI (6 نماذج ثابتة + النموذج الشغال) |
| /v1/chat/completions | POST | محادثة كاملة: تاريخ، system، بث، وأدوات |
| /api/think | POST | تفكير أعمق: مهلة أطول ونموذج Pro |
| /api/health | GET | حالة جلسة ACP وحالة المرساة |
| /api/reset | POST | يعيد تشغيل الجلسة ويحتفظ بالمحادثة |
| /api/session/new | POST | ينسى كل شي ويبدأ محادثة جديدة |
| /api/model | POST | يبدّل النموذج الشغال |
| /api/logs | GET | أرشيف المحادثات بصيغة JSON |
| /logs | GET | صفحة عربية تعرض الأرشيف |

كل الإعدادات تتغير من 20 متغير بيئة موثّقة في `.env.example`
(قياس: `grep -cE '^[A-Z]' .env.example`).

## لماذا بنيته

كل العملاء عندي يتكلمون OpenAI، وAntigravity ما عنده إلا واجهة تفاعلية.
الجسر خلّى 6 نماذج Gemini تشتغل مع أي عميل عادي، بدون ما أعدّل فيه ولا سطر.
